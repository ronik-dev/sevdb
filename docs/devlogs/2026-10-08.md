## Current Status
- **Build System:** Configured `CMakeLists.txt` for C17 and linked the Criterion testing framework.
- **Project Structure:** Established a standard C library layout with `src/`, `include/`, and `tests/`; isolated mathematical operations into a dedicated distance.c/distance.h module.
- **Memory Model:** Decided on a "Callee Allocates" (Heap) pattern utilizing flexible array members for dynamic vector sizes.
- **Implementation:** 
    - Defined `sevdb_vector` and `sevdb_database` structs.
    - Implemented vector memory allocation and deallocation (`sevdb_vector_create`, `sevdb_vector_destroy`).
    - Implemented database memory allocation and deallocation (`sevdb_db_create`, `sevdb_db_destroy`)
    - Implemented database basic push and search by id logic for vectors (`sevdb_db_push_vector`, `sevdb_db_get_vector_by_id`)
    - Implemented database basic vector removal functionality (`sevdb_db_remove_vector_by_id`)
    - Added better encapsulation with getters for `sevdb_vector` and `sevdb_database` structs.
    - Implemented Euclidean distance calculation for vectors (`get_euclidean_distance`).
    - Implemented Cosine Similarity calculation for vectors (`get_cosine_similarity`).
    - Implemented a robust Binary Min-Heap || Max-Heap Priority Queue (`pqueue`) to support efficient Top-K retrieval.
    - Implemented the actual database retrieval function (linear search `sevdb_db_search_k_similar_vectors`) to find and return the nearest vectors based on cosine similarity.
    - Implemented basic serialization: basic implementation to read and write to a binary file (`sevdb_db_serialize` and `sevdb_db_deserialize`), write to a temp file before "committing" to new save and checksum.
    - Implemented resize functionality (growing only) for database capacity.
    - Decided to keep id generation outside the db. Implemented duplicate id rejection.
    - Similarity search now returns similarity score alongside vecors (introduced `sevdb_similarity_scored_vector` struct in types.h")
    - Implemented `hashmap` to use as as key value store for sevdb sparse set.
    - Updated `sevdb_db_create`, `sevdb_db_destroy`, `sevdb_db_push_vector`,  `sevdb_db_get_vector_by_id`, `sevdb_db_remove_vector_by_id` to leverage new sparse set.
- **Testing:** 
    - Segmented tests into modular suites (`internal_test_suite`, `distance_test_suite`, `priority_queue_test_suite` and `hashmap_test_suite`).
    - All core operations math functions and data structures pass unit tests.
